# Course Recommendation Engine

Machine Learning Capstone Project developed as part of the **IBM Machine Learning Professional Certificate (2025)**.

## Project Overview

This project focuses on the design and evaluation of recommendation systems for a Massive Open Online Courses (MOOC) platform. The objective is to help learners discover relevant courses based on their interests, enrollment history, and course content.

The project explores both **Content-Based Filtering** and **Collaborative Filtering** approaches, comparing multiple Machine Learning techniques to identify the most effective recommendation strategy.

## Business Problem

As online learning platforms continue to grow, learners face an increasing number of available courses. Recommender systems help address this challenge by providing personalized suggestions, improving user experience, increasing engagement, and supporting learner retention.

## Objectives

* Analyze course enrollment data.
* Perform exploratory data analysis (EDA).
* Extract textual features using Bag of Words (BoW).
* Build content-based recommendation systems.
* Apply clustering and dimensionality reduction techniques.
* Develop collaborative filtering models.
* Compare recommendation approaches using offline evaluation metrics.
* Demonstrate recommendation capabilities through an interactive application.
